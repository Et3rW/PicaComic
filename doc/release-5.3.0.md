正式发布 5.3.0（5030）。这是一个紧急修复版：nhentai 网站改版后，应用里的 nhentai 什么都打不开，这一版修好了它。

### 修复

- **nhentai 打不开**（issue #7）：nhentai 把网站改成了浏览器加载后才显示内容的页面，进站前还要确认年龄。应用原来是从网页里读取漫画的，改版后首页、搜索、分类、详情、阅读、下载、评论和收藏都读不到了，有时还会反复弹出 Cloudflare 验证。现在全部改用 nhentai 官方提供的接口（https://nhentai.net/api/v2/docs）：
  - 首页（热门和最新）、搜索（所有排序、多标签、排除标签）、语言和标签分类、标签提示都能用了。
  - 打开一本漫画只发一次请求，详情和相关推荐一起拿到；登录后还会显示是否已收藏。
  - 阅读和下载的图片地址由 nhentai 指定的图片服务器给出。
  - 评论、网络收藏、加入和取消收藏（需要登录）也都换成了接口。
  - 一般不用再过 Cloudflare 验证。接口返回的普通错误不会再被当成验证，也不会再莫名弹出验证页。

### 注意

- nhentai 的接口限制了访问频率：不登录时，同一个 IP 每分钟大约只能搜索 10 次、翻 15 页列表；登录后翻倍。翻页太快时，应用会等几秒自动重试，还不行就提示"请求太频繁, 请稍后再试"，等一分钟就好。
- 登录状态和以前一样从网站登录页获取。如果以前登录过、现在网络收藏提示需要登录，请在设置里退出 nhentai 再重新登录一次。

### 其他

这一版只包含 nhentai 的修复。测试版里的其他新功能（rule34video 视频源、收藏夹随机、后台翻译和翻译任务、导出翻译数据等）会在 5.4.0 发布。
