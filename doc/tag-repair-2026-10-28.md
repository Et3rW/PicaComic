# 5.1.2 测试版：恢复 nhentai 列表标签

用户确认已选择“详细”模式，作品按每行一个显示，但卡片没有标签。

旧代码从新版内嵌 API 数据的 `tag_ids` 判断语言，却仍只从旧卡片的 `data-tags` 读取普通标签。新版卡片没有旧字段时，会出现“语言正常，标签为空”。两项回归测试在修改前均因标签列表为空失败，修改后通过。

修复将内嵌数据中的标签按作品 ID 建立索引，同步用于语言与标签读取。适用于首页热门/最新、首页翻页、搜索、收藏、分类、详情页推荐；保留旧 `data-tags`，去重并忽略未知或无效编号。每页只解析现有响应，不额外请求每部作品详情。

新增测试覆盖上述列表入口、单作品与列表数据格式、损坏数据块、数字/字符串编号、旧格式兼容、精确语言匹配，以及详细/简略模式下的标签控件显示。

本地回归测试共 26 项全部通过。静态检查为 0 个错误、26 个已有警告和 131 个已有提示，与修复前基线相比没有新增诊断。
