# 5.1.3 测试版：标签排序与中文分页

用户反馈：作品详情点击标签后，除“最近”之外的排序均 404；中文分类的热门排序翻页重复第一页，而日语和英语正常。

分类网络层此前将热门排序拼成 `/tag/<name>/popular-*?page=N` 或 `/language/<name>/popular-*?page=N`。本次让热门分类复用应用已有的 `/search/` 入口，通过命名空间搜索词、`sort` 和 `page` 明确传入筛选与排序。多词分类使用引号包裹；分类浏览不写入搜索历史。“最近”保留分类地址。搜索 URL 使用 URI 查询参数编码。

同时修复搜索与分类的总页数解析：此前提取链接中的所有数字，会把搜索词和编码中的数字一并算作页数。现在只读取分页链接的 `page` 参数，支持嵌套链接、无 last 链接但有下一页的情况。

验证：新增 13 项测试，覆盖六类标签跳转、四种热门排序、中日英各前三页、最近模式、全局语言筛选、搜索历史、包含数字的搜索词、分类词编码及分页链接。模拟服务器对旧标签热门路由返回 404，对旧中文热门路由始终返回第一页；新入口按页返回不同作品。旧代码的首批 11 项测试全部失败；修复后完整 39 项测试通过。静态检查为 0 错误、26 个已有警告及 131 个已有提示，没有新增诊断。

限制：直接访问网站返回 HTTP 403，无法在此环境确认真实服务器的搜索结果、热门排名及分页行为。上述测试验证客户端路由、参数和响应解析，不代替手机实网验证。尤其需要检查中文热门第二、三页，以及多词标签的热门结果是否仍属于所选标签。
