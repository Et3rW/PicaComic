# 5.1.4 测试版：禁漫登录无限等待

用户反馈禁漫天堂登录一直转圈。本次确认并修复客户端中几处会卡住或误标记登录状态的路径：

- 自动选线路原先只在某条线路返回 401 时完成；全部失败或没有响应时，Completer 永不完成。现在每条探测有 12 秒上限，全部失败返回明确提示；探测结束取消余下请求并关闭连接。仅将包含 API 错误字段的 401 视为有效线路，避免选中代理的 HTML 错误页。探测不发送账号密码。
- 登录 POST 增加 30 秒总期限及取消请求；代理设置读取也有限时。API 选线、域名更新和版本信息读取不再无限等待。
- 失败后不再执行图片线路更新和签到；成功后这些操作在后台运行，并禁止它们再次触发自动登录，避免递归重登。
- 只有成功登录才保存账号；异常、重复点击和页面退出时正确处理加载状态。退出登录后不接受尚未完成的旧登录结果。
- 支持登录返回数据中的 AVS 会话字段（兼容解密数据或外层响应中的 `s`），保留 CookieManager 对响应头 Cookie 的处理。实现参考了 [JMComic-Crawler-Python 的 API 登录实现](https://github.com/hect0x7/JMComic-Crawler-Python/blob/master/src/jmcomic/jm_client_impl.py)，但未使用任何真实用户凭据。
- 网络错误显示状态或操作建议，不把密码、会话或原始异常内容写入新增日志。

新增 18 项网络与页面测试，覆盖线路全失败/超时/迟到结果、有效线路识别、密码错误、后台初始化、并行登录、异常响应、取消登录、凭据保存、会话 Cookie、请求取消，以及页面停止加载和重试。完整 57 项测试通过。静态检查仍为 0 错误、26 个已有警告和 131 个已有提示，没有新增诊断。

实网限制：对四条内置线路的公开版本信息 GET 检查中，两条返回 403，另两条未解析到可用版本号。这不能证明用户手机上的线路状态，也不代表已经验证真实账号登录成功。未发送真实账号密码，未绕过访问验证。手机测试若收到“所有 API 线路均不可用”，应在漫画源的禁漫设置中更新 API 域名，或关闭自动选择后手动切换，再观察明确错误信息。
