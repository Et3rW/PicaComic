## 已修改

- nhentai 退出登录：修复空 URI 路径与 Cookie 默认 `/` 路径不一致；认证 Cookie 按名称清除所有路径，同时保留验证 Cookie 和其他站点的数据。同步清除认证备份。
- 登录识别：仅 `access_token` 或旧版 `sessionid` 可表示登录，不再把任意名称含 token/session 的字段当作登录成功。
- 登录持久化：将浏览器存储中的明确认证字段合并保存，保留刷新凭据；验证 Cookie 与对应 User-Agent 一起保存。
- 登录生命周期：取消会结束等待；重叠探测只处理一次；取消后的异步结果不能再次保存登录态或关闭其他页面；打开桌面窗口失败可被捕获。
- 收藏状态：只读取当前漫画的 API 数据；缺少按钮不再默认已收藏。JSON 原文优先解析，避免标题中的 HTML 字符被错误处理。
- 网络日志：隐藏认证头、Cookie、令牌和密码；认证请求正文及无法安全结构化的正文不写入日志。此修改不会改变实际网络请求。
- iOS 模拟器工作流：上传组件由 v3 改为 v4；尚未运行远端工作流。
- README 的 Flutter 版本改为与现有锁定依赖匹配的 3.47.0，未升级依赖。
