正式发布 5.2.0（5020）。这一版的主要新功能是**图片翻译**，另外加入了应用内更新，修复了绅士漫画无法登录。发布前经过了 5 个 Android 测试版（5.1.9.1 ～ 5.1.9.5）。

### 新功能

- **图片翻译（仅 Android）**：在阅读器里把漫画页上的文字翻译成目标语言，译文画在原来的位置上。文字在手机上识别，只把识别出的文字发给翻译服务，图片不会上传。思路参考了 [ccbkv/PicaComic](https://github.com/ccbkv/PicaComic)。
  - 识别用 PaddleOCR 的两个模型（约 21 MB），能识别简繁中文、日文和英文，横排、竖排都可以。模型不随安装包附带，第一次使用时在设置里下载。
  - 翻译服务支持 OpenAI 兼容接口、Claude、Gemini，以及不用 key 的 Google 翻译。预设了 OpenAI、Claude、Gemini、DeepSeek、通义千问、智谱 GLM、Kimi、豆包、硅基流动、OpenRouter、Ollama 和自定义接口，选好服务商、填上 key 就能用；编辑页可以从服务商拉取当前可用的模型列表。
  - 目标语言：简体中文、繁体中文、英文、日文、韩文。已经是目标语言的文字不会再翻译。
  - 进入阅读器默认是原图。点工具栏的翻译按钮后整本显示译文：从当前页开始在后台把本章翻完，翻到下一章会接着翻。按钮外圈显示进度；连续 3 页失败（比如 key 错误、额度用完）会停下并提示原因。再点一下换回原图。
  - 每页的识别和翻译结果都会保存，同一页只请求一次。key 单独保存，不随应用数据同步。
  - 设置在 设置 → 阅读 → 图片翻译，阅读器的设置面板里也有入口。
- **应用内更新（Android）**：检查到更新后点“下载”，应用会下载新版、用发布附带的 SHA256SUMS 校验，再调起系统安装，数据都会保留。第一次需要允许“安装未知应用”。其他平台仍然打开发布页。
- **设置 → 关于 里加了“检查更新”**。

### 修复

- **更新提示显示不全**：更新说明超过 5 行时，前 5 行会被丢掉，内容长了也没法滚动。现在显示全部内容，可以滚动。
- **绅士漫画无法登录**：网站登录时要拖滑块，应用里的账号密码表单显示不了，所以一直登不上。现在点“登录”会打开网站自己的登录页，登录后应用自动保存登录状态。应用不再保存密码，登录过期后先退出再重新登录。

### 版本号

从这一版起，正式版的版本号末位都是 0：5.2.0 之后是 5.3.0。末位留给两个正式版之间的测试版，按 1 ～ 9、a ～ f 数（5.2.1 ～ 5.2.f）。正式版只会提示正式版的更新，测试版只会提示测试版的更新。

### 已知限制

- 图片翻译只能在 ARM64 的 Android 设备上用；x86_64 设备、iOS 和 macOS 上显示“暂不支持”。
- 原文是被一块和气泡同色的底盖住的，不是擦掉后重画。纯色气泡里看不出来，文字压在画面上时会留下色块。
- 翻译服务预设里的模型名可能会过时，可以在编辑页重新拉取。
- 绅士漫画的网页登录是按“登录后书架页不再提示需要登录”来判断成功的，网站改版后可能需要调整。

下载 **PicaComic-5.2.0.apk**，Android 7.0+，ARM64 / x86_64。安装包从 65 MB 增加到约 82 MB，多出来的是图片识别用的运行库。

使用和 5.1.5 ～ 5.1.8 相同的固定发布签名和应用标识 **com.github.et3rw.pica_comic**，可以直接覆盖安装，不用重新登录。从这一版起，以后的更新可以在应用里直接下载安装。

### iOS

下载 **PicaComic-5.2.0-unsigned.ipa**，要求 **iOS 15+**。这是 ARM64 真机 release 包，需要自行签名安装，不是 App Store / TestFlight 包。应用标识为 **com.github.pacalini.picaComic**。

### macOS

下载 **PicaComic-5.2.0-macos-universal.zip**，要求 **macOS 12.4+**，支持 **Apple 芯片和 Intel**。解压后将应用放入“应用程序”。应用采用本地临时签名，未使用 Apple 开发者证书，也未公证，首次打开可能被系统安全提示拦截。
